# 我的生活

只供个人在本机桌面浏览器使用的工作生活记录 App。

第一版包含首页、今日待办、快速备忘、健身、饮食、游戏娱乐、学习、心情和本地数据设置。应用不需要登录，不连接云服务，也不会把个人记录上传到网络。

## 环境

- Node.js 24 或兼容版本
- pnpm 11
- 最新版 Microsoft Edge 或 Chrome

## 安装

```powershell
pnpm install
```

## 开发运行

```powershell
pnpm dev
```

默认地址为 `http://127.0.0.1:5173`。Vite 启动后会显示实际端口。

## 本地预览

```powershell
pnpm build
pnpm preview
```

构建产物位于 `dist/`。应用不需要线上部署。

## 数据保存

- 记录通过 IndexedDB 保存在当前浏览器的持久化存储中。
- 正常刷新、关闭浏览器和使用同一浏览器配置重新打开后，数据仍会保留。
- 清除浏览器网站数据、使用不保留数据的隐私窗口或更换浏览器配置可能造成数据丢失。
- 运行数据保存在浏览器数据库中；使用者可见的本地数据文件是通过“数据与设置”导出的 JSON 备份。

备份文件包含：

- 待办和快速备忘。
- 健身、饮食、娱乐、学习和心情记录。
- 外观模式和八个页面的颜色。
- 备份格式版本、导出时间和记录数量。

恢复时先预览备份信息，确认后才会覆盖当前记录。清空全部数据需要输入“清空”进行二次确认。

## 测试

```powershell
pnpm typecheck
pnpm lint
pnpm test
pnpm test:e2e
```

- `pnpm test` 运行 Vitest 单元测试和 IndexedDB 集成测试。
- `pnpm test:e2e` 会先执行生产构建，再使用本机 Edge 运行 Playwright 端到端测试。
- 全部测试完成后可执行 `pnpm build` 再次生成最终构建。

## 第一版边界

- 不支持多人、登录、权限或共享。
- 不提供云同步和跨设备同步。
- 不提供实际游戏和影视内容。
- 不提供专业健康、营养、心理或学习建议。
- 不包含 AI 分析、复杂统计或系统提醒。
